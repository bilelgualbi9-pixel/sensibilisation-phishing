# sensibilisation-phishing
La sensibilisation au phishing forme les utilisateurs à repérer les escroqueries par mail ou SMS. Les pirates exploitent l'urgence pour voler des identifiants. Pour se protéger, il faut vérifier l'adresse réelle de l'expéditeur, survoler les liens avant de cliquer, se méfier de la pression et signaler tout message suspect à l'informatique.
